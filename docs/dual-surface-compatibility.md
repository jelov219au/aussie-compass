# 웹·설치형 앱 동시 제공 계약

Hoju Compass의 웹사이트와 "앱"은 별도 제품이 아니다. `src/app/manifest.ts`의
`start_url`과 `scope`가 `/`인 동일한 Next.js App Router 사이트를 홈 화면에
설치하는 PWA다. 따라서 새 기능과 콘텐츠는 한 라우트, 한 컴포넌트 계층, 한
데이터 계약을 공유하는 것이 기본이다.

## 구현 전 호환성 검토

새 기능을 제안하거나 구현하기 전에 아래 항목을 확인하고 사용자에게 짧게
결과를 알린다.

- 데스크톱 웹, 모바일 웹, 설치형 PWA에서 같은 핵심 결과를 얻는가?
- 작은 화면, 키보드, 스크린 리더와 44px 이상의 터치 대상에 맞는가?
- `localStorage`, 파일, 카메라, 알림 등 브라우저 API의 지원 차이가 있는가?
- 저장값이 기기·브라우저·설치본별이라는 점을 정확히 안내하는가?
- 오프라인, 네트워크 실패, 외부 사이트 이동 시 안전한 대체 경로가 있는가?
- 서버 비밀과 공식 데이터 출처가 클라이언트 번들·URL·로그에 노출되지 않는가?

판정은 `호환`, `주의사항과 함께 호환`, `차단됨` 중 하나로 기록한다.

호환되면 두 표면을 같은 변경으로 함께 출시한다. 특정 플랫폼 API에서만 가능한
기능이면 progressive enhancement로 구현하고, 지원되지 않는 표면에는 같은
목적을 달성할 수 있는 대체 동작과 설명을 제공한다. 대체 경로도 불가능해 결과가
크게 달라지면 코드를 쓰기 전에 범위와 영향을 보고한다.

## 구현 규칙

1. 공용 라우트·컴포넌트·출처 registry를 재사용하고 웹/앱용 복사본을 만들지 않는다.
2. 홈 노출이 필요한 기능은 실제 `src/app/page.tsx`에 mount하거나 홈에서 도달
   가능한 탐색 요소에 연결한다. 사용되지 않는 컴포넌트 문자열은 완료 근거가 아니다.
3. 실시간 수집, 푸시 알림, 지도 마커, 오프라인 사용처럼 구현하지 않은 능력을
   이름이나 문구로 암시하지 않는다.
4. 외부 지도·정부 페이지가 필요한 기능은 온라인 전용 경계를 표시하고, 외부로
   전달되는 검색어나 위치 범위를 버튼 가까이에 설명한다.
5. 서비스 워커 캐시 범위를 넓히는 변경은 개인정보·오래된 공식 데이터 위험을
   별도로 검토하고 테스트하기 전에는 하지 않는다.

## 현재 교통·공사 확인 기능의 경계

`/rail-work-alerts`는 웹과 설치형 PWA가 동일하게 쓰는 공용 라우트다. 관심 지역과
체크 상태는 해당 브라우저의 로컬 저장소에만 남으며 계정 동기화가 아니다. 지도와
NSW·VIC·QLD 교통기관 및 정부 페이지는 인터넷 연결이 필요하다. 현재 기능은
실시간 자동 알림, 푸시, 자체 지도 마커 또는 자동 정부 데이터 수집을 제공하지
않는다. 서비스 워커는 `/offline` 안내만 미리 저장하므로 오프라인 재실행에서 이
도구가 열린다고 보장하지 않는다.

일반 브라우저와 설치형 PWA의 저장 공간이 분리된 환경에서는 `/data-transfer`의
수동 JSON 백업·복원으로 관심 지역을 옮길 수 있다. 자동 동기화로 표현하지 않는다.

## 완료 확인

- 관련 기능 계약 테스트와 `npm run lint`를 통과한다.
- Production build를 통과한다.
- 320px, 768px, 1440px에서 내용·CTA·외부 링크 경계를 확인한다.
- 설치형 PWA와 일반 브라우저에서 같은 라우트와 핵심 결과를 확인한다.
- 저장·재실행·오프라인·외부 링크 동작을 실제 브라우저에서 확인하고, 검증하지
  못한 기기나 동작은 완료로 표현하지 않는다.
