## 이 패킷의 약속

AI가 일반적인 답과 영문 예시를 빠르게 주는 상황에서 Hoju Compass는 답을 더 길게 반복하지 않는다.

```text
공식 기준 확인
→ 내 실제 경험과 상황 입력
→ 계산·비교·체크리스트 저장
→ 지원할 공고가 생겼을 때만 Resume Pro 결과물 준비
```

모든 유입면에서 무료 정보와 도구를 먼저 보여준다. Resume Pro는 실제 지원할 공고가 정해져 회사별 이력서·커버레터·제출 전 체크리스트가 필요한 사람에게만 연결한다.

## 공통 UTM 규칙

- `utm_campaign`: `resume-pro-action-14d-202608`로 고정한다.
- `utm_source`: 실제 플랫폼만 쓴다. 계정명, 그룹명, 사용자 이름은 넣지 않는다.
- `utm_medium`: 검색은 `organic`, 커뮤니티는 `community`, 짧은 영상은 `video`, 파트너는 `referral`을 쓴다.
- `utm_content`: 아래 승인된 영문 소문자·하이픈 값만 쓴다. 문구를 바꾸면 새 값을 만들고 기존 링크를 덮어쓰지 않는다.
- URL에는 검색어 원문, 이름, 이메일, 공고명, 회사명이나 커뮤니티 이름을 넣지 않는다.
- Resume Pro의 `from`은 현재 허용된 값만 쓴다. 파트너용 `launch-partner`는 개발 팀이 허용목록에 넣기 전까지 배포하지 않는다.
- 한 소재를 시험하는 동안 첫 문장과 CTA를 동시에 바꾸지 않는다.
