## 정렬 기준

첫 결제 가능성은 `지금 지원할 공고가 있는가`, `현재 문제가 Resume Pro 결과물과 가까운가`, `무료 도구를 거친 뒤에도 다음 일이 남는가`, `채널에서 신뢰를 얻을 수 있는가`를 기준으로 정했다.

아직 채널별 표본이 없으므로 아래 순서는 성과 결론이 아니라 발행 우선순위 가설이다. 경로별 분모가 10회 미만이면 순위를 확정하지 않는다.

## 발행 공통 게이트

아래 항목을 모두 통과한 자산만 발행 후보가 된다.

- 발행 당일 실제 랜딩에서 무료 도구가 열리고 저장·완료까지 동작한다.
- Resume Pro가 실제 판매 중일 때만 `A$19.90 1회 결제·구독 없음` 문구와 링크를 노출한다. 결제가 닫혀 있으면 Pro 문장과 링크를 뺀다.
- Workforce Australia와 Fair Work 링크가 열리고, 문안이 해당 기관의 일반 안내 범위를 넘지 않는다.
- 정부·기관이 Hoju Compass를 추천·인증·제휴한다는 인상을 주지 않는다.
- 이름, 이메일, 계정명, 커뮤니티명, 회사명, 공고명과 검색어 원문을 UTM에 넣지 않는다.
- 24시간 평가는 링크·규정·안전 점검이다. 72시간에도 최소 표본이 없으면 성과 결론을 내리지 않는다.
- 중복 청구, 결제 뒤 접근 불가 또는 개인정보 노출은 표본과 관계없이 해당 링크 유입을 즉시 중단한다.

## 1순위 · 검색 1 — 호주 이력서 성과 문장

### 대상 의도

호주 이력서를 지금 작성하고 있으며, AI나 예시 사이트에서 찾은 문장을 자신의 경력에 어떻게 맞출지 알고 싶은 사람.

### 연결 랜딩

1. `호주 영문 이력서에서 경력을 성과로 바꾸는 법`
2. Workforce Australia Resume planner
3. 무료 Resume Builder
4. 실제 지원 공고가 있는 사람만 Resume Pro

첫 문장: `호주 이력서 성과 문장, AI 예시를 복사하기 전에 내가 실제로 설명할 수 있는 경험부터 골라보세요.`

무료 CTA: `예시를 보고 내 경력으로 바꾸기`

Pro 연결: `기본 이력서 작성과 PDF 저장은 무료예요. 실제 지원할 공고가 정해져 회사별 이력서·커버레터·제출 전 체크리스트가 필요할 때만 Resume Pro를 이용하세요. 1회 A$19.90이며 구독은 없어요.`

### 예상 행동

검색 결과 클릭 → 공식 작성 항목 확인 → 실제 경험으로 성과 문장 작성 → 무료 이력서 저장·PDF → 공고가 있으면 Resume Pro 방문.

무료 도구만으로도 `설명할 수 있는 경력 문장과 기본 이력서 PDF`가 남으므로 가치는 완결된다.

### 게시 전 사실검증

- Resume planner 링크와 PDF가 열리는지 확인한다.
- 공식 자료가 모든 호주 고용주의 동일한 형식을 요구한다고 쓰지 않았는지 확인한다.
- 무료 Resume Builder의 저장·PDF 기능을 직접 완료한다.
- Resume Pro 판매 상태, A$19.90, 1회 결제, 구독 없음과 결과물 범위를 실제 랜딩에서 확인한다.

### 커뮤니티·플랫폼 규정 확인

검색 메타 자산이므로 커뮤니티 규정은 해당하지 않는다. 유료 검색 광고로 전환하지 않으며 제목·설명이 랜딩 내용과 일치하는지만 확인한다.

### 24시간·72시간 판정

- 24시간: 색인·링크·무료 도구·Pro 판매 상태만 확인한다. CTR 결론은 내리지 않는다.
- 72시간: 노출 100회 이상이면 CTR 4% 이상을 유지 신호로 본다. 2% 미만이면 제목·설명만 수정한다.
- 글 조회 20회 이상이면 무료 도구 이동률 10% 이상을 유지 신호로 본다. 3% 미만이면 무료 CTA만 수정한다.
- Resume Pro 방문 20회 미만이면 결제 가능성을 판단하지 않는다.

## 2순위 · 짧은 영상 2 — 공고 하나를 지원 묶음으로

### 대상 의도

지원할 공고를 이미 찾았고 회사별 이력서와 커버레터를 다시 만드는 일이 번거로운 사람.

### 연결 랜딩

무료 Resume Builder를 첫 링크로 두고, 설명란 두 번째 링크에서 Resume Pro를 선택할 수 있게 한다.

첫 문장: `지원 공고를 찾았는데 또 처음부터 이력서를 쓰고 있나요?`

무료 CTA: `내 실제 경력 저장 → 공고 원문과 확인`

Pro 연결: `기본 경력 저장과 PDF는 무료예요. 실제 공고에 낼 이력서·커버레터·체크리스트 묶음이 필요한 경우에만 Resume Pro를 1회 A$19.90에 이용하세요.`

### 예상 행동

영상에서 결과물 구조 확인 → 무료 빌더에서 기본 경력 저장 → 공고가 있으면 Resume Pro 방문 → 결제 전 예시와 조건 확인 → 필요할 때 Checkout 시작.

결제하지 않아도 `재사용 가능한 기본 이력서와 PDF`가 남는다.

### 게시 전 사실검증

- 샘플 공고·회사·경력이 모두 가상인지 확인한다.
- 무료 빌더에서 입력·저장·PDF까지 직접 완료한다.
- Resume Pro가 공고 점검, 회사별 이력서, 커버레터와 제출 전 체크리스트를 실제 제공하는지 확인한다.
- A$19.90와 구독 없음, 취업 결과를 보장하지 않는다는 문구를 실제 랜딩과 맞춘다.

### 커뮤니티·플랫폼 규정 확인

YouTube의 외부 링크, 상업성 콘텐츠와 오해를 부르는 표현 관련 규정을 게시 당일 확인한다. 합격 보장, 정부 인증, 실제 채용공고 도용 또는 이용자 개인정보가 없어야 한다.

### 24시간·72시간 판정

- 24시간: 영상 프레임의 개인정보, 링크 오류, 오해성 댓글과 접근 실패만 확인한다.

## 3순위 · 커뮤니티 2 — 공고별 이력서 반복 작성

### 대상 의도

여러 공고에 지원하며 이력서 버전과 다음 행동이 섞였거나, 공고마다 처음부터 다시 쓰는 사람.

### 연결 랜딩

`호주 구직, 지원서를 꾸준히 관리하는 방법` → 무료 Job Application Tracker → 공고가 정해졌을 때 Resume Pro.

첫 문장: `공고마다 이력서를 처음부터 다시 쓰기보다, 기본 이력서 하나에 실제 경험을 모아두고 맞는 내용만 앞으로 옮기는 편이 덜 힘들어요.`

무료 CTA: `공고와 다음 확인 날짜 남기기`

Pro 연결: `지원 일정 관리만 필요하면 무료 트래커를 이용하세요. 공고에 맞춘 이력서·커버레터·제출 전 체크리스트가 필요할 때만 Resume Pro를 이용할 수 있어요. 1회 A$19.90, 자동 구독 없음.`

### 예상 행동

질문에 대한 답을 읽음 → 개인정보 주의사항 확인 → 공고·마감일·다음 행동 저장 → 실제 지원 자료가 필요한 사람만 Resume Pro 방문.

무료 도구만으로도 `지원 기록과 다음 행동`이 남아 가치가 완결된다.

### 게시 전 사실검증

- Fair Work 개인정보 안내 링크가 열리는지 확인한다.
- 여권번호·TFN·은행정보를 기록하지 말라는 안전 문구가 유지되는지 확인한다.
- 무료 트래커의 저장·수정·완료 흐름을 직접 확인한다.
- Pro 가격과 판매 상태를 게시 당일 확인한다.

### 커뮤니티·플랫폼 규정 확인

- 외부 링크, 서비스 언급, 상업성 게시와 반복 게시 허용 여부를 확인한다.
- 질문이 있는 글에만 답하고 새 홍보 글이나 DM으로 사용하지 않는다.
- 운영자가 사전 허가를 요구하면 게시 전에 문안과 링크 승인을 받는다.
- 같은 커뮤니티에서 동일 링크를 14일 안에 반복하지 않는다.

Workforce Australia Resume planner → 무료 Resume Builder → 실제 공고가 있는 사람만 Resume Pro.

무료 CTA: `공식 항목 확인 + 내 경력 무료 저장`

Pro 연결: `무료 이력서만 사용해도 됩니다. 실제 지원할 공고가 정해져 회사별 이력서·커버레터·체크리스트가 필요할 때 Resume Pro를 1회 A$19.90에 선택할 수 있어요.`

### 예상 행동

세션 후 QR 열기 → 공식 항목 확인 → 무료 경력 저장·PDF → 실제 공고가 있는 참가자만 Resume Pro 방문.

무료 경력 초안과 PDF로 세션 후속 행동이 끝까지 성립한다.

### 게시 전 사실검증

- 공식 자료 링크, 무료 기능과 Pro 가격·범위를 확인한다.

- QR 인쇄 전 최종 URL과 모바일 화면을 확인한다.
- `launch-partner`가 유입 허용목록과 성과표에 반영됐는지 개발 팀 확인을 받는다.

### 커뮤니티·플랫폼 규정 확인

파트너 담당자의 서면 승인을 받고 로고·명칭 사용 범위를 확인한다. 참가자 명단, 이메일 또는 개인별 QR을 요구하거나 제공하지 않는다. 유료 추천 관계가 있다면 발행 전에 표시 문구를 별도 검토한다.
