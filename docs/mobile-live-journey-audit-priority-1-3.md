## 1순위 · 검색 — 호주 이력서 성과 문장

### 모바일 첫 화면 메시지

live 첫 화면에는 다음 내용이 한 화면 안에 보였다.

- `호주 공통`, `공식 자료로 확인한 글`
- 제목: `호주 영문 이력서에서 경력을 성과로 바꾸는 법`
- 설명: 하던 일을 나열하지 않고 구체적인 영문 성과 문장으로 바꾸는 법
- 공유와 나중에 보기 저장

첫 화면만으로 글의 대상과 무료로 얻는 내용을 이해할 수 있다. 다만 발행 패킷의 AI 맥락인 `예시 복사 전 실제 경험 확인`은 첫 화면에 직접 드러나지 않는다.

### 공식 출처 도달성

글 하단의 공식 자료 영역에서 다음 두 링크가 모두 열렸다.

- Workforce Australia Resume planner PDF: 정상 도달
- Fair Work Ombudsman `Our recruitment process`: 정상 도달

공식 자료를 열기 전 한국어 요약과 `내 조건에 따라 달라질 수 있으니 원문 확인` 안내가 있다. Fair Work 자료가 한 기관의 채용 절차 예시이며 모든 고용주의 동일한 형식이 아니라는 제한도 표시된다.

공식 출처까지는 스크롤 후 링크 1회 클릭이다.

### 저장·재사용 가능성

- 입력 내용은 현재 브라우저에 자동 저장된다.
- 무료 PDF와 텍스트 복사가 가능하다.
- JSON 작성본 백업과 불러오기를 제공해 기기 이전·재사용 경로가 있다.
- 첫 화면과 Footer에서 브라우저 저장임을 반복해 알린다.
- 공용 기기나 브라우저 데이터 삭제 시 사라질 수 있다는 설명은 개인정보 안내 페이지에 있지만 Builder 첫 화면에는 직접 보이지 않는다.

### Resume Pro 연결 시점

두 지점에서 연결된다.

1. 글의 `이 글을 읽은 다음` 영역에서 무료 빌더와 Resume Pro를 나란히 제시한다.
2. 무료 빌더 필수 내용 7/7이 되면 `기본 이력서 준비 완료` 영역에서 `무료 PDF로 저장하기`와 `지원할 공고에 맞게 다듬기`를 함께 제시한다.

따라서 글에서는 Pro가 무료 결과 완성 전에 보이지만, 빌더에서는 무료 이력서가 준비된 뒤 다시 제안된다. 후자의 시점이 비강매 원칙과 잘 맞는다.

### 구매·환불·개인정보 신뢰 표시

Resume Pro live에서 다음을 확인했다.

- 모바일 첫 화면에 `A$19.90`, 1회 결제, 구독 없음 표시
- 실제 경험만 사용, 취업 결과를 과장하지 않는다는 제한
- 결제 버튼 전 구매 조건 확인 체크박스
- 서비스 이용 조건, 구매·환불 안내, 개인정보 안내 링크
- Stripe 보안 결제와 결제 뒤 작업 공간 제공 안내
- 판매자명, ABN, 지원 이메일, 영수증·인보이스, 이용권 복구와 Australian Consumer Law 관련 해결 절차
- 전체 카드번호·CVC를 Hoju Compass가 직접 받지 않는다는 안내
- 이력서·커버레터 내용은 이용권 데이터베이스에 저장하지 않는다는 안내

신뢰 정보는 충분하지만 구매·환불 세부 내용은 첫 화면 아래 링크를 열어야 확인할 수 있다.


### 저장·재사용 가능성

- 브라우저 자동 저장, PDF, 텍스트 복사, JSON 백업·불러오기가 있다.
- 필수 내용 완성도와 live 미리보기로 진행 상태를 알 수 있다.
- 무료 결과만으로 기본 이력서를 완성하고 다음 지원에 재사용할 수 있다.
- 기기 간 자동 동기화는 없으며 사용자가 백업 파일을 관리해야 한다.

### Resume Pro 연결 시점

필수 내용 7/7이 되면 `무료 PDF로 저장하기`와 `지원할 공고에 맞게 다듬기`가 함께 나타난다. 직접 Builder로 들어온 사용자에게는 적절한 시점이다.

다만 영상 설명란의 별도 Pro 링크는 무료 완성 전에도 접근할 수 있다. 한 영상에서 무료 링크와 Pro 링크를 같은 강도로 병렬 표시하면 강매처럼 보일 수 있다.

### 구매·환불·개인정보 신뢰 표시

- Builder 첫 화면에서 브라우저 저장을 명확히 표시한다.
- Pro로 이동하면 가격, 구독 없음, 구매 조건 체크, 환불·개인정보·Stripe 안내를 확인할 수 있다.
- Builder 첫 화면에는 가격·환불 문구가 없으며, 무료 사용 중 불필요한 결제 압박도 없다.

### 판정

**HOLD**

무료 도구 자체의 문제는 아니다. `공고 하나의 지원 묶음`이라는 영상 약속, 공식 근거 확인, 일반 Resume Builder 첫 화면 사이의 연결이 약해 발행 전에 설명란과 링크 순서를 고쳐야 한다.

이 공백은 강매를 줄이는 장점이 있지만, 실제 공고를 저장한 고의도 사용자가 다음 문서 준비 방법을 찾기 어렵게 만든다.

### 구매·환불·개인정보 신뢰 표시

- 글과 Tracker에서 브라우저 저장, 서버 미전송, 민감정보 최소화 안내가 보인다.
- 글의 Resume Pro 링크를 선택하면 가격·구독 없음·구매 조건·환불·개인정보·Stripe 안내가 나타난다.
- Tracker 안에서는 유료 상품이나 가격을 노출하지 않아 무료 도구만 이용해도 흐름이 완결된다.

### 판정

**LAUNCH**

질문에 먼저 답하고 공식 출처·무료 기록 도구를 제공한다. Pro 전환이 없어도 `공고와 다음 행동 저장`이라는 목적이 완전히 해결되므로 커뮤니티 유입에 적합하다.

### 수정 필요 문구

커뮤니티 답변의 마지막을 다음처럼 줄인다.

> 무료 트래커에 공고 하나와 다음 확인 날짜부터 저장해보세요. 그 공고에 낼 이력서와 커버레터가 필요해졌을 때만 Resume Pro를 확인하면 됩니다.

가격은 커뮤니티 답변 본문에서 반복하지 않고, Resume Pro 랜딩에 들어간 뒤 확인하게 한다. 이미 무료 CTA와 Pro CTA가 글 하단에 함께 있으므로 커뮤니티 게시물에 두 링크를 모두 넣지 않는다. 커뮤니티에는 글 링크 하나만 사용한다.

## live와 배포 예정 변경 구분

### 현재 live Resume Pro

- 제목: `지원하고 싶은 공고를 찾았다면, 이제 제출할 준비를 끝내세요.`
- 첫 설명: 무료 빌더의 실제 경력을 바탕으로 공고 누락 확인, 회사별 이력서와 커버레터 준비
- 첫 CTA: `이력서가 없다면 무료로 먼저 만들기`
- `Pro 작업 공간 이용 가능`은 상태 표시이며 클릭 CTA가 아니다.
- 모바일 첫 화면 안에 A$19.90, 1회 결제, 구독 없음과 무료 CTA가 보인다.

### 작업 트리에 저장된 예정 변경 · 아직 live 아님

- 제목 후보: `AI로 문장을 찾았다면, 이번 공고에 낼 지원 자료로 남기세요.`
- `내 실제 경력 저장 → 공고 원문과 확인 → 제출할 묶음으로 저장` 3단계
- 결제가 열려 있을 때 `이번 공고 지원서 묶음 만들기`를 Checkout 영역으로 연결
- 무료 Builder를 두 번째 CTA로 배치

공개 사이트 점검에서는 예정 변경이 보이지 않았다. 따라서 이 문서의 launch/hold 판정은 현재 live 문구와 구조만을 기준으로 한다. 예정 변경은 개발 팀 통합·배포 뒤 별도 모바일 재점검이 필요하다.

## 발행 전 최종 게이트

- 1순위는 검색 설명 한 문장만 승인한 뒤 발행 후보로 둔다.
- 2순위는 설명란 링크 순서와 무료 우선 문구가 승인될 때까지 보류한다.
- 3순위는 커뮤니티에 글 링크 하나만 사용하고, 해당 커뮤니티 규정 확인 뒤 발행 후보로 둔다.
- 어떤 자산도 실제 게시 전 Resume Pro 판매 상태와 가격을 다시 확인한다.
- 결제 뒤 접근 실패, 중복 청구 또는 개인정보 노출이 한 건이라도 확인되면 관련 유입을 즉시 중단한다.

이 점검 과정에서 실제 결제 시작, Checkout 이동, 폼 제출, 다운로드, 외부 게시·발송은 하지 않았다.
