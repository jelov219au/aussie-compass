# 차량 사전검사 공급자 데이터 기준

## 목적과 현재 범위

Hoju Compass가 향후 중고차 사전검사 사업자를 비교·중개할 경우, 초보 구매자가
광고 문구가 아니라 같은 기준으로 서비스 범위와 이해상충을 판단할 수 있도록 하는
최소 데이터 계약이다. 현재 `/used-car-comparison`은 자동차협회 또는 공식 성격의
출발점만 중립적으로 연결한다. 리드 수집, 예약 대행, 추천 수수료, 유료 노출,
추천 순위 판매는 구현하지 않는다.

## 공급자 필수 필드

| 필드 | 형식과 검증 기준 |
| --- | --- |
| `provider_id` | 내부 불변 식별자. 상호 변경 시에도 재사용하며 공개 순위 키로 쓰지 않는다. |
| `legal_name`, `trading_name`, `abn` | ABN Lookup 등 공식 등록 정보와 일치 여부, 마지막 확인일, 확인 출처를 함께 저장한다. |
| `service_regions` | 주·준주, 도시·우편번호 또는 거리 반경, 제외 지역, 출장 할증 경계를 구조화한다. “전국”처럼 검증 불가능한 표현만 허용하지 않는다. |
| `delivery_mode` | `mobile`, `workshop`, `remote_video`를 복수 선택할 수 있다. 각 방식별 주소·작업공간·판매자 동석 조건을 둔다. |
| `independence` | 판매자·딜러·수리업체·플랫폼과의 소유·소개·수익 관계, 검사 뒤 수리 수익 가능성, 추천료를 구체적으로 고지한다. |
| `qualifications` | 검사자 개인 자격, 수리업 면허, 자동차협회·업계단체 승인, 발급기관, 번호, 유효기간과 검증 출처를 분리한다. 단순 회원과 인증을 같은 표현으로 합치지 않는다. |
| `inspection_scope` | 엔진/모터, 냉각, 변속기, 브레이크, 조향·현가, 차체·사고 흔적, 타이어, 전장, 진단 스캔, 하부, road test 등 포함 항목을 방식별로 표시한다. |
| `exclusions` | visual-only 여부, 부품 탈거·압축검사·리프트·배터리 상태검사·ADAS·LPG·개조 부품 등 미포함 항목과 접근 불가 시 처리 방식을 명시한다. |
| `sample_report` | 실제 형식의 비식별 샘플 URL, 사진·영상·등급·결함 우선순위·수리비 추정 포함 여부, 보고서 전달 형식과 보관기간을 기록한다. |
| `duration` | 현장 검사 예상 시간, 예약부터 검사까지 예상 기간, 보고서 전달 시간을 각각 범위로 표시한다. |
| `price` | 기본가, GST 포함 여부, 회원가 조건, 차령·차종·거리·긴급 예약 할증, 추가 검사와 재검 비용, 가격 확인일을 둔다. “from” 가격만으로 비교하지 않는다. |
| `insurance` | 전문배상·공공책임보험 보유 여부, 보험자, 증서 유효기간, 보장 한도 확인 여부를 저장한다. 민감한 증서 원본은 공개하지 않는다. |
| `vehicle_capabilities` | EV/하이브리드 배터리 진단, 4WD, 수입·고성능·클래식·개조·캠퍼밴 등 차종별 `supported`, `limited`, `unsupported`와 필요한 추가 장비를 표시한다. |
| `complaints_refunds` | 불만 접수 채널·응답 목표, 판매 완료·접근 불가·날씨·road test 불가 시 취소/환불, 재검·오류 정정 절차, 외부 분쟁조정 경로를 기록한다. |
| `source_provenance` | 각 주장별 공식 URL, 수집일, 마지막 사람 검토일, 원문 요약, 만료 또는 다음 재검토일을 저장한다. |

## 공개 전 품질 게이트

1. 법적 사업자 정보, 서비스 지역, 검사 방식, 범위·제외, 총가격 조건, 취소·불만
   경로가 모두 확인돼야 한다. 누락된 공급자는 “정보 부족” 상태로 두고 추천 또는
   예약 가능한 사업자처럼 노출하지 않는다.
2. 독립성 고지는 공급자 자기진술과 플랫폼이 확인한 사실을 구분한다. 딜러가 비용을
   지불하거나 검사 뒤 같은 업체가 수리 견적을 내는 경우도 숨기지 않는다.
3. 자격·협회 표시는 발급기관과 유효기간을 검증한다. “qualified”, “approved”,
   “expert” 같은 표현을 증빙 없이 플랫폼 문구로 재사용하지 않는다.
4. 검사 상품 변경이 잦으므로 공급자 공식 페이지를 정기 재검증하고, 예약 직전
   구매자가 범위·가격·지역을 다시 확인하도록 안내한다. 링크 실패 또는 확인 기한
   경과 시 예약 CTA를 숨기고 검토 상태로 되돌린다.
5. 샘플 보고서와 약관이 실제 판매 상품과 일치하는지 확인한다. visual-only 검사와
   리프트·분해가 가능한 기계 검사를 같은 상품군 또는 점수로 합치지 않는다.

## 중립 노출과 향후 중개 원칙

- 기본 정렬은 사용자가 선택한 지역과 서비스 적합성처럼 설명 가능한 기준만 쓴다.
  결제액, 수수료 또는 광고비가 순서에 영향을 주면 “추천” 결과와 분리하고 명확히
  표시한다.
- 공급자 수수료, 지분 관계, 제휴 또는 리드 대가가 생기면 CTA 가까이에 고지한다.
  유료 노출이 품질 인증처럼 보이게 하지 않는다.
- 평점·불만 수치는 표본 수, 기간, 검증 방식과 이의제기 절차 없이 공개 점수로
  만들지 않는다. 플랫폼 내부의 수동 판단을 객관적 품질 순위로 표현하지 않는다.
- 구매자의 연락처·차량 위치·VIN은 예약에 꼭 필요한 시점에 최소 수집하고, 공급자
  전달 범위·보관기간·삭제 방법에 동의받는다. 현재 버전에서는 어떤 리드 정보도
  수집하지 않는다.

## 현재 공식 출발점 기록

페이지의 2026-08-30 검토 기준은 VIC RACV, QLD RACQ, WA RAC, SA RAA, TAS RACT,
NT AANT, NSW/ACT의 NRMA 안내 RedBook Inspect다. 이는 사업자 전체 목록이나 품질
순위가 아니다. 특히 NRMA 경로의 RedBook Inspect는 공식 안내상 `visual and
non-mechanical` 검사이며, 표시된 현장 서비스 지역 밖에서는 Remote Video
Assessment가 제시되므로 현지 정비사 워크숍 검사와 별도 범주로 유지한다.
