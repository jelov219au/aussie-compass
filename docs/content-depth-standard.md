# 정보 콘텐츠 깊이 기준

Hoju Compass의 정보 콘텐츠는 단순한 개요나 링크 모음에 머물지 않고, 초기 정착자가
현재 상황을 판단하고 다음 행동까지 옮길 수 있게 한다. 이 기준은 데스크톱 웹,
모바일 웹, 설치형 PWA가 공유하는 같은 라우트와 데이터에 적용한다.

## 적용 범위

- `/resources/[slug]`의 데이터 기반 실무 글
- 임금, 세금, 주거, 이동, 정착처럼 설명 자체가 핵심인 독립 가이드
- 계산기·체크리스트 페이지의 결과를 해석하고 실행하는 보조 설명

개인정보·약관·결제 안내처럼 목적이 다른 페이지를 길이만 늘리기 위해 확장하지
않는다. 계산기와 체크리스트도 도구 기능을 가리는 장문을 추가하지 않는다.

## 한 페이지가 답해야 하는 질문

1. 이 페이지는 사용자가 어떤 결정을 내리도록 돕는가?
2. 가장 먼저 확인할 공식 기준과 적용 순서는 무엇인가?
3. 일반 규칙이 그대로 적용되지 않는 예외와 제외 항목은 무엇인가?
4. 실제로 비교·예약·문의·신청할 때 무엇을 확인해야 하는가?
5. 문제가 생겼을 때 어떤 기록과 증빙을 남겨야 하는가?
6. 읽은 뒤 바로 할 수 있는 다음 행동은 무엇인가?
7. 서로 대체하지 못하는 별도 확인은 무엇인가?
8. 공식 정보의 기준일과 원문 출발점은 어디인가?

## 작성 원칙

- 한국어 설명과 필요한 영어 용어를 함께 써서 공식 페이지에서도 같은 개념을 찾을
  수 있게 한다.
- 금액, 기한, 자격, 법적 절차처럼 바뀔 수 있는 내용은 공식 제공자·정부 원문에서
  직접 확인하고 기준일을 표시한다.
- 한 사업자를 유료 추천 순위처럼 보이게 하지 않는다. 선택 기준과 이해상충을 먼저
  보여 주고, 서비스 범위·가격·제외 항목은 예약 또는 신청 시 다시 확인하게 한다.
- 사용자의 기록·사진·서면 확인이 필요한 지점을 구체적으로 쓴다.
- 법률·세무·의료 조언을 대신한다고 표현하지 않고, 관할·계약·개인 조건에 따른
  차이를 명확히 표시한다.
- 외부 공식 링크는 인터넷 연결이 필요하며, PWA에서도 같은 URL과 콘텐츠를 쓴다.

## 현재 품질 하한선

2026-08-31 공휴일 중복 통합 후 데이터 기반 리소스 글 35개는 각각 최소 6개 핵심 섹션과
3개 공식 출처를 가진다. 전체 합계는 377개 섹션과 244개 출처다. 기존 공휴일 주소는
308 영구 이동으로 보존하고 읽기 기록은 통합 글에 연결한다. 독립 가이드는
페이지 목적에 맞게 아래 요소를 조합하며, 단순히 섹션 수만 채우지 않는다.

- 판단 순서 또는 의사결정 흐름
- 예약·신청·문의 전 체크리스트
- 예외, 제외 항목과 별도 확인 사항
- 보고서·영수증·사진·서면 답변 같은 증빙
- 결과를 받은 뒤 협상·수정·철회·신고 등 다음 행동
- 기준일이 있는 공식 원문 링크

## 변경 시 검토

콘텐츠를 추가하거나 큰 폭으로 수정할 때 `npm run test:content-depth`를 실행한다.
모바일 320px, 태블릿 768px, 데스크톱 1440px에서 제목·표·선택기·외부 링크가
잘리거나 가로로 넘치지 않는지도 확인한다. 외부 링크를 오프라인 기능으로
오인하게 하지 않고, 브라우저 로컬 저장은 기기 간 동기화가 아님을 가까운 곳에
안내한다.
