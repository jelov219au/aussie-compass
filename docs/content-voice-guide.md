# Hoju Compass 한국어 문장 기준

Hoju Compass의 문장은 호주 생활이 낯선 한국어 사용자가 부담 없이 다음 행동을 찾도록 돕는다. 정확해야 하지만 기관 안내문처럼 멀게 느껴지지 않아야 한다.

## 기본 목소리

- 따뜻하고 차분하게 설명한다.
- 사용자를 재촉하거나 평가하지 않는다.
- 서비스 내부 용어보다 사용자가 얻는 도움을 먼저 말한다.
- 한 문장에는 한 가지 내용만 담고, 가능한 한 짧게 쓴다.
- `~하세요`가 연달아 나오지 않도록 `~할 수 있어요`, `~해 두면 좋아요`, `~부터 살펴볼까요?`를 상황에 맞게 섞는다.
- 무조건 반말처럼 느껴지지 않도록 존중하는 해요체를 기본으로 한다.

## 화면 제목과 작은 제목

- 장식용 영어 문구는 쓰지 않는다. 제품명, 호주 공식 용어와 기관명만 영어를 유지한다.
- `Product principles`, `Official sources, explained`, `Application workflow`처럼 내부 기획 문구는 사용자 관점의 한국어로 바꾼다.
- 추상적인 표현보다 지금 무엇을 할 수 있는지 보여준다.

예시:

- `Product principles` → `Pro를 만드는 기준`
- `Official sources, explained` → `공식 자료도 함께 살펴봤어요`
- `Application workflow` → `지원 준비 순서`
- `Find your answer` → `막막한 순간에 찾아보세요`

## 피할 표현

- `구조입니다`, `검증합니다`, `구분합니다`, `제공합니다`처럼 서비스를 설명하는 내부 문장
- `완료하세요`, `진행하세요`, `확인하세요`가 연달아 나오는 명령형 문장
- 근거 없이 불안을 키우는 표현과 결과를 보장하는 표현
- 영어와 한국어를 분위기만을 위해 섞는 표현
- 사용자가 잘못했다는 느낌을 주는 경고문

## 정확성이 우선인 경우

결제, 개인정보, 세금, 비자, 고용 권리, 긴급 연락처에서는 따뜻한 말투보다 오해 없는 표현이 우선이다. 다만 핵심 경고 뒤에는 사용자가 무엇을 하면 되는지 짧고 구체적으로 안내한다.

## 최종 점검

새 문구를 공개하기 전에 다음을 확인한다.

1. 한국어로 소리 내어 읽었을 때 자연스러운가?
2. 내부 담당자가 아니라 사용자에게 말하고 있는가?
3. 명령형 표현이 불필요하게 반복되지 않는가?
4. 영어가 꼭 필요한 공식 용어인가?
5. 불안만 남기지 않고 다음 행동을 알려주는가?
