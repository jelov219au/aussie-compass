# 모바일 홈과 설치 진입점 — 2026-08-31

호환성: **주의사항과 함께 호환**.
동일한 홈 URL과 컴포넌트, 검색·저장 계약을 웹/모바일/설치형 PWA에서 사용한다.
설치 경고는 OS/브라우저가 결정하며 사이트에서 해제하거나 우회하지 않는다.

## 사용자 흐름과 변경

- 모바일의 긴 소개와 장식 카드보다 검색을 먼저 보여준다.
  기존 `HomeSearch`를 공용 Hero 안에 한 번만 배치했다.
  제목과 설명을 줄이고 바로 찾는 주제를 8개에서 4개로 정리했다.
  검색 기능이나 상세 자료는 제거하지 않았다.
- 380px 미만에서는 주제 버튼을 2×2, 넓은 휴대폰에서는 4개 한 줄로 배치한다.
  검색·주제 버튼과 주요 탐색 대상은 44px 이상을 유지한다.
- 소개 다음에 명확한 `/install` 링크인 ‘홈 화면에 추가하기’를 배치한다.
  팝업, 자동 설치, 추가 권한, 설치 상태 저장은 사용하지 않는다.
- 공용 CSS의 display-mode 미디어 조건으로 standalone/fullscreen/minimal-ui에서는
  홈 설치 카드와 기존 재방문 영역의 설치 링크를 숨긴다.
  브라우저 이름 추측이나 hydration 후 화면 교체를 추가하지 않았다.
- 주요 도구 네 개를 영어 문장 소개보다 먼저 보여주고, 2열 카드의 제목·설명을 줄였다.
  원래 도구 URL, 상세 설명 페이지, 출처와 검색 개인정보 보호 계약은 유지한다.
- 설치 페이지 첫 문구를 간결하게 바꿨다. Samsung Internet의 출처 경고 설명은
  필요한 사용자만 펼치는 안내로 제공한다. 보안 해제·알 수 없는 앱 허용을 요구하지 않고,
  Chrome 안내 또는 웹 이용으로 연결한다. Chrome에서도 경고가 나면 진행하지 않도록 한다.
- 재방문 문구는 짧게 정리하되, 기기 간 자동 동기화가 아니라는 경계를 유지한다.

## 검증

- 전체 `npm run lint` 및 수정 파일 ESLint 통과.
- 최종 `npm run build`의 TypeScript와 141개 정적 페이지 생성 통과.
- 기존 core-accessibility, visual-hierarchy, cross-surface-content,
  site-search-resume-intent, mobile-pwa-usability, home-pro-ready-now 계약 검사 통과.
  시각 조정 후 관련 변경 파일/검색 계약을 다시 확인했다.
- 실제 Chrome의 문서화된 viewport 제어로 로컬 Production 빌드를 확인했다.
  홈 320×568, 390×844, 768×1024, 1440×900에서 가로 넘침 없음.
  각 clientWidth/scrollWidth는 305/305, 375/375, 753/753, 1425/1425px.
- 320px 홈 검색창 상단은 약 299px로 첫 화면 안에 위치한다.
  320px의 긴 placeholder가 잘리는 것을 확인하여 짧은 검색 예시로 수정했다.
- ‘집 구하기’ 주제 클릭과 ‘이력서’ 직접 입력/Enter 모두 `/search`로 도착한다.
  주소에 검색어가 없고, 결과 입력값과 관련 결과가 화면에 표시됐다.
  저장소를 직접 읽거나 변경하는 검증은 하지 않았다.
- 홈 설치 카드 → `/install` → 기기별 안내 앵커 이동 확인.
  320px에서 안내 위치 약 96px / 헤더 하단 73px, 포커스는 `manual-install`.
- 출처 경고 안내 클릭으로 열림, Enter로 닫힘 확인. summary 높이는 44px.
- 점검 중 브라우저 error/warn 로그 없음. 결제나 구매 복원 경로는 실행하지 않았다.

## 증거와 한계

화면 캡처는 현재 작업의 시각 자료 디렉터리에 저장한다:
`C:/Users/jelov/.codex/visualizations/2026/08/31/01a0564f-8139-7362-a82a-4432cc963ce9/`.

`mobile-home-320.png`, `mobile-home-390.png`, `mobile-home-768.png`,
`mobile-home-1440.png`는 로컬 수정본이며 공개 사이트 화면이 아니다.

사용자는 Android/Samsung Internet에서 설치 후 주소창 없는 메뉴 화면을 제공했고,
설치 과정에 ‘출처를 알 수 없는 앱’ 승인이 필요했다고 보고했다.
이것은 변경 전 화면의 제한된 증거다. 새 홈의 실제 Android/iPhone 설치본,
display-mode 조건에 따른 설치 권유 숨김, iPhone 설치, Chrome 경고 없는 설치,
화면 읽기 프로그램, 오프라인·재실행·OS 복귀를 실기기에서 통과했다고 주장하지 않는다.
기존 ACT 지역명 표시 이슈는 이 홈 작업의 수정 범위에 포함하지 않았다.
